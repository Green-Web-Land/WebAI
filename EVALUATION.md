# Evaluation status and contributions

WebAI pre-releases are for evaluation, usability feedback and development workflow testing. Use synthetic data for evaluation. See [release qualification](RELEASE-QUALIFICATION.md) for the exact candidate's completed checks and remaining limits. Earlier developer and independent QA results apply only to their recorded predecessor artifacts and scopes.

The combined candidate has focused developer verification against its actual distribution image, recorded in the qualification document. A working earlier preview or prior bounded QA does not establish complete acceptance of this new image.

Broader Windows/macOS Docker-host operation, real-provider interoperability, full accessibility/translation coverage and every reverse-proxy configuration are not established by this release. Public demo operators remain responsible for hosting policy, network security, data retention and their external HTTPS setup.

## Feedback

Report the page, expected and actual behavior, reproducible steps, application version and operating environment through the repository's Issues. Use redacted screenshots and synthetic examples. Do not attach credentials, personal records or complete runtime backups.

Translation contributions should preserve template keys and placeholders and identify the template/application version. Interface translation does not translate user documents.

Read the software licence and supplied third-party notices before redistribution. Third-party components retain their own terms; model or educational-content licences do not license the application.
