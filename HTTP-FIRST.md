# HTTP-first installation

The IP-only instructions have been consolidated into
[Install WebAI v0.9.2-preview.1](INSTALLATION.md).

Use that single guide for Windows, macOS and Linux, local-only or LAN IP
addresses, separate application/mail ports, first sign-in and recovery.

[Connection choices](HTTPS-SETUP.md) explains optional external HTTPS and the
difference between browser HTTP and validated outbound mail TLS.
[Security boundaries](SECURITY.md) explains the risks of unencrypted HTTP.

These guides target v0.9.2-preview.1. They do not change
the behavior of the published v0.9.0 image or authorize mixing release files.
